# 情绪点模板（moments，逐字使用）

> 本文件是**情绪点（moments）结构的权威定义方**。`managing-lessons-store/SKILL.md` 只指向这里，不复制。
> **必须逐字使用**。
> 情绪判定公式与 userwords 共用一套（见 `retro-collect/assets/userwords-template.md`）——**对象主判据，情绪由对象+核心意图推出**，不自创第二套。

## 落点

`<KB>/projects/<项目标识>/<YYYY-MM-DD>-moments.md`（**按天分文件**——每天一个，防单文件膨胀/覆盖；日期 = session 日期，不是执行当天——定法以 `retro-collect/SKILL.md`「第 0 步」为权威定义方）

与同目录 `<日期>-facts.md` / `<日期>-userwords.md` 并列。

## 触发（谁有权写）

两条写路径：

1. **agent 主动**——察觉用户情绪时**当场记**，不用问用户（主路径，平时就在记）。
2. **`retro-collect` 重扫**——跑到 collect 时按当前公式重扫本 session 全对话，覆盖本 session 那批（补漏，见下节）。

与 userwords 的区别：userwords 只在跑 collect 时才产；moments 平时就在记，collect 只负责重扫补漏。

## 重扫与覆盖（`retro-collect` 跑时）

collect 时按**当前**判定公式**重扫本 session 全对话** → `moment drop`（清本 session 旧条目）→ `moment add` 逐条重写。**直接覆盖，不留旧版**——对话还在，随时可再生成。

**前提：本 session 对话仍完整可见。** 若已被压缩 / 截断（扫不全）→ **不要 drop**：残缺的新数据盖掉完整的旧数据 = 静默丢数据。此时只补新发现的，或先告诉用户「对话已不全，不覆盖」。

**只覆盖本 session 的条目**：按天文件里可能并存多个 session，`moment drop --session <S>` 只清这一个，其余原样保留。

## 记什么（三类极性，全收）

| 极性 | 收什么 | 去向 |
|---|---|---|
| **负面** | 用户不满意（对事纠正的轻负面 / 对人的重负面） | 规则管线（可能立规矩），要结案 |
| **正面** | 用户认可（「你这个想法好」= 对人正面） | 画像管线，不结案 |
| **认知** | 提问/回答暴露的判断倾向 | 画像管线，不结案 |

**好的也留**——画像只有负面 = 投诉日志，不是人物画像。正面/认知是画像的主要原料。

## 情绪判定公式（与 userwords 共用，不在此重写）

按 `retro-collect/assets/userwords-template.md` 的公式：
1. 有脏字 → 情绪波动标记，剥掉看核心
2. 核心意图：夸→正面 / 贬→负面 / 中性→中性
3. **对象（人/事）决定强度**：对人→情绪重；对事→情绪轻（对事的纠正是中性）
4. 「负面」≠ 骂得脏；「好的」≈ok 无评价词=中性

## 模板

```markdown
# 情绪记录（moments）

> 格式权威定义见 `managing-lessons-store/assets/moments-template.md`（本文件只放数据）。
> 触发：agent 察觉情绪当场记（不问）；collect 时重扫覆盖本 session。极性：负面 / 正面 / 认知，全收。
> 判定公式与 userwords 共用（对象主判据，情绪由对象+意图推出）。
> 负面必填**原话**（不猜原因/态度）；原因/态度为可选，写则标「（推断）」。

---

## M-<日期>-<N>

- 极性：<负面|正面|认知>｜项目：<标识>｜session：<session_id>｜message：<id 或 —>｜时间：<YYYY-MM-DD>
- 状态：<未解决|已解决>（仅负面；正面/认知写「—」）
- 问题 / 认可 / 倾向：<一句话>
- 判据（思考过程）：<对象→意图→脏字→结论 的推导，如「对象=人（主语你+否定理解）→ 无脏字 → 核心意图=贬 → 负面」>
- 证据（原话）：
  > <用户原话，逐字>
- 原因（推断，可选）：<若有，须标推断>
- 态度（可选）：<若有，须标推断>
- 解法：（结案时补）｜代价：（结案时补）
```

## 硬约束

1. **负面必填证据（原话）**——不猜原因/态度。猜的部分须显式标「（推断）」
2. **判据（思考过程）必填**——已有定性（极性）就必须写下推导（对象→意图→脏字→结论），否则无法复核
3. **只记情绪点**，不做价值判断——「这句话说明了什么」归分析阶段
4. **好的也留**（正面/认知）——不因为「不是负面」而漏记
5. 写库前查 `<KB>/.migrating`：存在 → 拒绝写入
6. **原子写**（临时文件 + 改名）+ **无 BOM**

## 常见错误

| 错误 | 纠正 |
|---|---|
| 负面只填 `--cause` 没有原话 | 原话（evidence）必填；原因只是可选推断 |
| 正面/认知漏记 | 它们是画像主原料，必须记 |
| 把「对事的纠正」当情绪爆发 | 对象=事 → 中性/轻负面，不是重情绪 |
| 自创格式 | 模板必须逐字使用 |
