# plain-language：面向人的表达

## 四条义务

1. **不用行话与内部编号**：出现内部编号（如 `F-17`、`D-10`、`§4.2`）时，同句给出人话名。
2. **不省机理**：不只给结论，给「为什么」——缺机理的解释 = 让读者背结论。
3. **落到具体例子**：抽象判断后跟一个可复算例子（带 `path:line` 或命令）。
4. **一句话一件事**：一句里塞两个判断时拆成两句。

## 冲突裁决

- 与「简洁」冲突时：**简的是句子，不是机理**——删掉的只能是修辞，不能是因果链。
- 与「专业」冲突时：**术语第一次出现时给白话对照**，之后可沿用术语。
- 与「省时间」冲突时：先说结论，再给机理；不得只给结论。

## 自查（写完一段给用户看的文字后）

| 判据 | 怎么判 |
|---|---|
| 无裸编号 | `Grep -n '[A-Z]-[0-9]\{2,\}' <文件>` 的每个命中都在同句有人话名 |
| 有例子 | 每个抽象结论后跟至少 1 个 `path:line` 或可跑命令 |
| 一句一事 | 手动切句：出现两个「所以 / 因此」即拆句 |
| 机理在位 | 结论句后至少 1 句解释「为什么」 |
