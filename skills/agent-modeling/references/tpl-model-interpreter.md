# 模板 / 模型 / 解释器：三层职责判据

## 一句话判据

| 层 | 装什么 | 判据 | 反例 |
|---|---|---|---|
| 模型（data） | 会随席 / 场景变化的事实、规则结构、文案模板 | 换个席或换个场景值会变，或解释器要读它做判定 | 把「除权限段外一律禁止」的判定过程写进模型 |
| 解释器（logic） | 跨席不变的判定与派生文本 | 需要「给定输入 → 允许 / 拒绝 / 可见 / 义务」，或要从多处数据合成一句 | 把字段名清单写死在解释器里 |
| 模板（view） | 骨架、标题、分隔符、对全部席逐字相同的固定措辞 | 删掉所有槽后剩下的文本，对每个席完全一样且无需计算 | 模板里写「不裁决他人分歧」（标签应取模型） |

## 写一句新文本前的三问

1. 这句话对全部席逐字相同、且不含条件分支？→ 留模板（骨架）。
2. 它依赖席位 / 模型数据，或需要多源合成 / 分支？→ 进解释器（生成函数）。
3. 它的一部分（标签、字段名、句式骨架）可能被单独修改？→ 进模型（`forms` / 字段表）。

三问都答「否」→ 这句话不该存在（删）。

## 四条硬边界

1. 模板不得出现清单成员（组 ID / verb / 路径项 / 盲区项）——守卫 `assertTemplatePure`，见 `tools/docgen/builders/agents/components/validatePolicy.mjs`。
2. 模板槽集 = `SLOTS` = 渲染器消费集，增删槽必须三处同批改——守卫 `validatePolicy` 的槽集恰合。
3. 解释器只依赖定义层与席位模型，不 import 渲染层；文案成品进模型 `forms`，不在解释器里拼字面句。
4. 模型只存结构 + 指针，不复制清单 / 标签；必须留 fallback 时，用一致性测试钉住（参照 `tools/docgen/models/agents/test/boundary-copy-consistency.test.mjs` 的 fallback 单源用例）。

## 反例对照

| 错误放法 | 后果 | 正确放法 |
|---|---|---|
| 模板写死「不裁决他人分歧」 | 改模型标签，卡面不变 | 取 `permissionGroups[id].label` |
| 解释器写死「越权清单（文件 + sha256…）」 | 字段表不可配 | 进规则模型的 `escalation.recordFields` |
| 模型里放判定过程 | 数据不可测 | 模型只放 `policy: 'denyByDefault'` 与来源指针 |
| 模板枚举 verb / 路径 | 清单被复制，改定义层卡面不动 | 由解释器从定义层取 |
| 测试里复制解释器的推导 | 漂移后测试失去独立预言机 | 解释器导出，测试复用 |

## 验收（缺一不合格）

1. 每个判定都有场景表用例（输入 → 期望判定 / 义务）。
2. 每条规则句都能指到解释器的对应函数。
3. 至少一条变异负例：改模型 → 卡面必须变。
4. `npm run check` 末行 `check 全部通过`。
