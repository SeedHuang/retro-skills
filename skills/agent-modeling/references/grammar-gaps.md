# 语法部件与缺口

## 八类语法部件

建模时只认这八类；任何一段卡面文字先归到其中一类，再决定去处。

| # | 部件 | 例子 | 去处 |
|---|---|---|---|
| 1 | 身份 | 「你是评审席」 | `seat.id` / `seat.display` |
| 2 | 触发 | 「当议长调度时」 | `seat.triggers` / `timing` |
| 3 | 动作 | 「逐条核对」 | `duty.action` / `checklist` |
| 4 | 对象 | 「对交付物」 | `duty.action.objects` |
| 5 | 判据 | 「结果只能是 hit/miss/na」 | `checkCriteria.*.observable` |
| 6 | 规则 | 「不得只提问题不给解法」 | `must` / `never` + `predicates` |
| 7 | 落点 | 「写回 round-check.md」 | `forms` / `outputs` / `defaultLanding` |
| 8 | 异常 | 「越界写盘则停手上报」 | `escalation` / `permissions` |

不属于这八类的（流程说明、病根、历史）不出现在卡面模型里。

## 缺口四元组

拆解发现落不下的叶子，产出一条：

```
{ path, code, missing, fixTarget }
```

`code` 闭集七值：`Expr`（表达式缺定义）/ `Ref`（引用无登记）/ `Enum`（取值不封闭）/ `FieldId`（字段无 id）/ `Negation`（否定形态不可判）/ `Display`（只展示、不进逻辑）/ `Migration`（现役事实与模型不一致，需先对齐）。

`fixTarget` 只能是：`改文案` / `补模型` / `交人`。

## 四型断点

| 型 | 症状 | 处置 |
|---|---|---|
| A 复合句 | 一句两事，拆开两边都不完整 | 拆句 |
| B 指代不明 | 两个主语，不知说谁 | 先绑主语 |
| C 谓语缺定义 | 动词读得懂，写不出判法 | 去代码/文档找定义所在行 |
| D 真冲突 | 两句各自成立，放一起矛盾 | 不拆，交人 |

## 四态终止

| 态 | 含义 | 处置 |
|---|---|---|
| `Closed` | 取值封闭（枚举/数字/已登记 ID/正则） | 通过 |
| `Display` | 不被任何 op 读取 | 允许，标 `display` |
| `NeedDef` | 抽象谓词 | 进 P2 用「属加种差」展开 |
| `NeedTranslate` | 拆不动、被读取、无定义可展开 | **文案本身不合格**，回 P4 重写 |

`NeedTranslate` 是重点：它不是模型不够，是句子没说清。

## 拆解算子

| 层 | 按什么拆 | 拆不动的信号 |
|---|---|---|
| 段 | 句号、分号 | 整段一句且含多个动词 |
| 句 | 并 / 且 / 同时 / 时 / 则 / 若 / 除非 | 有连词，拆完两边都不完整 |
| 子句 | 主谓宾抽取 | 找不到主语或谓语 |
| 要素 | 动词→`action`；名词→`record`；条件→`Expr`；数量→`value`；落点→`ref` | 动词无登记、名词无契约 |
| 叶子 | 枚举 / 数字 / ID / 正则 | 仍是自由字符串 |

## 做完核对

对每一次拆解产出两样东西，缺一不合格：① 四态标注后的叶子清单；② 缺口四元组清单（可为空，但要写出「0 条」）。两份都要能反查到卡面原文的段名与句序。
