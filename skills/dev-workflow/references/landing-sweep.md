# 落地后回扫：改掉所有声明它的地方

> 触发：建脚本 / 加规则 / 完成待办 / 任何「落地」之后。

## 判据

一件事落地后，必须回头扫一遍所有声明它的地方，把过时描述改掉，才可宣布完成。

## 扫四类地方

1. 源码注释：脚本头部的用法说明、函数旁注释。
2. 各仓库 README / 说明文档。
3. 架构文档 / spec / plan：尤其「待办 / 未做 / 缺 / 待验证」字样与数字。
4. 规则正文：路径、命令、计数。

## 扫描命令

`Get-ChildItem <范围> -Recurse -File -Include *.md,*.mjs | Select-String -Pattern '未做|未验证|待建|缺|待定|TODO'`

## 数字类

凡文档写数量，优先只留一处并附取数命令；同一数字写在多处必然漂移。

## 产出

把命中的每一处逐条对照现状改掉，再收口；缺「逐条处置」不得宣布完成。
