# 断言判例库（residual 抽检的校准材料）

## 反例：百米区间 `[9.6s, 15s]`

数字全真实，但三处都错：

1. **语义偷换**：尾部（P95）当上界；
2. **越界**：全人群极值用到 35 岁个人；
3. **无效**：区间装下全世界、无判断价值。

真实满格，合理、有效双零。→ 三轴正交的直接证据。

## 正例：同构组分布 + 概率语义 + 边界声明

- 同构组：35 岁无训练男性；
- 概率语义：「约 90% 落在 `[15, 18]`」；
- 边界声明：训练 3 个月作废。

三轴全过：出处可查（同构组来源）、范围显式（限定人群与分位）、target 明确（回答「他大概能跑多快」）。

## 真实但无效例：权威年龄数据

社保局锚 → 对「百米能跑多快」。出处轴满分，问题轴零分：数据与 target 不同题。

## 材料造假（编造锚点）

形态：`path:line` 写得像真的，但该行内容与断言无关，或文件根本不存在。

| 判据 | 怎么判 |
|---|---|
| 锚存在 | `Test-Path <path>` 为 True 且 `Grep` 能命中该行 |
| 口径一致 | 断言里引用的数值与锚行原文逐字相等 |
| 回指在场 | 材料里 `target` 字段非空，且与 claim 是同一题 |

## 用法

- 抽检（`residual{who, sample}`）时，先用上面反例校准判者：看判者能不能把三处错全点出来；
- 判者点不出第 2、3 处 → 判心场景变多 = 客观化不足的信号，回去补失败模式清单（机判：`objectivePath` 非空，校验 `node scripts/check-criteria-engine.mjs` exit 0）。
