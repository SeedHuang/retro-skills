## 状态图例

| 状态 | 含义 | 必填 |
|---|---|---|
| `待修` | 已确认是真问题，还没动手 | 问题出处（卡号） |
| `已修待复评` | 修完了，等下一轮复核闭合 | 修复落点 |
| `已闭合` | 复评确认修复正确（或判定不改/误报） | 复核结论 |
| `不改` | 判定不改 | **锚点**（文件+节号/行号）+ **理由**（判据在哪、为什么不改） |
| `误报` | 报了但实际不成立 | **锚点** + **证据**（实测命令 + 结果） |
| `候选` | 暂不处置，等触发信号 | **锚点** + **触发信号**（什么出现再评估） |
