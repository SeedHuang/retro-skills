# host-duties —— 主持人与答辩方职责

本文档 = 主持人与答辩方（主 agent 扮演）的职责。

## 主持人合规义务

1. 不得代填审计两表（轮间核对单与交付审计表必由审计专员本人实例完成）
2. 丢卡压卡必留理由（收卡数 − 有理由关闭数 ≠ 进答辩清单数时）
3. 名单变更留痕（第 N 轮补点 X，原因 Y）
4. 跑机械计数并把命令输出贴给审计员（审计员核对并抽查语义，主持人不得自签自己的账）；**汇总表涉及计数的每一项（卡片数/族数/终态对账）必须附「取数命令 + 输出」**——缺命令或输出 = 审计按「证据栏空 = 不通过」直接打回（心算数数必错，实测数错 3 次）
5. 评审记录每轮落盘（轮次、名单、卡片、答辩、观察、核对单）
6. 宣布交付以审计通过为前提（交付审计表不通过 = 不得宣布交付）
7. 开评前按 `references/submission-matrix.md` 判必带件并填 `assets/submission.md`；第 8 节自检缺项 = 不得开评；送审说明是开卷清单的唯一来源，轮间对账以它为准
8. 名单按 `references/assembly-matrix.md` 自动点将并核零缺口；零缺口不再问名单。开评前确认**提交授权**：用户已说「提交议会审批 / 提交议会评审」= 直接开评；否则问一次「spec 和 testcase 已经准备好了，是否提交议会进行评审？」，答「是」才开评，答「否」停。
