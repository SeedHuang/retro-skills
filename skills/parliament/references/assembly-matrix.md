## 硬规矩

1. **最低法定人数 = 覆盖矩阵零缺口**：本文档类型涉及的关注面，被点名者每面有人；缺口 = 名单不合法，不得开始（侦探核漏点）。
2. **自动点将**：主持人按矩阵出名单并核覆盖矩阵零缺口；**零缺口 = 自动开评，不再单独请用户确认**。只有三种情况请用户确认：① 有覆盖缺口且无法按矩阵补齐；② 高风险 / 不可逆事项需要用户拍板；③ 用户明确要求看名单。
3. 轮间补点必须留痕（第 N 轮补点 X，原因 Y）。
4. 名单 + 轮间变更记录附进最终报告（评审质量对账凭据）。

## 花名册常驻、按需点将

点将 = 从 13 席花名册里挑，不是临时造角色；未点名席不参与本轮但存在；侦探无条件常驻。

## 轮间补点

第 N 轮补点 X 必须留痕（原因 Y），记录进最终报告。

## 自扩展（加席）

复制现有角色数据 → 填新席清单 → 跑 `node skills/parliament/scripts/gen-agents.mjs` 重新生成 → 跑 `node skills/parliament/scripts/gen-agents.mjs --check`；**禁止手改 `agents/*.md`**。
