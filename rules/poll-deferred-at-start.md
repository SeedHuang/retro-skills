# 开工时轮询推迟项

> 来源：套件初始化（KB 尚未 bootstrap，暂无条目 ID）｜证据：2026-09-27 设计对话「推迟项跨 session 蒸发」讨论；定版见**复盘套件 spec 的 §7.2**（仓库 `retro-skills`，相对路径 `docs/superpowers/specs/2026-09-27-retro-suite-design.md`）｜落地：2026-09-27

会话开始时先用 `managing-lessons-store` 技能跑推迟项轮询（`lessons deferred`），逐条核对「复活信号」。

- 有命中 → 动手前先向用户提出：命中项编号 + 信号证据，并说明是否升格为独立 spec。
- 无命中 → 一句话报告「推迟项 N 条，均未命中信号」。

报告必须含当前计数（让进度可见，防轮询退化成形式主义）。
错题集位置由脚本解析，规则里不硬编码路径——换位置无需改规则。
