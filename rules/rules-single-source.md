# 全局规则只建在源仓库，运行时只读

> 来源：L-020｜证据：2026-10-02 跑 `aas` 体检实测「需建链接 1」——`rule-global-ask-before-acting.md` 已建在 `my-rules\rules\`，运行时无链接，该规则从未生效过｜落地：2026-10-02

**新建全局规则一律建在 `my-rules\rules\`，禁止直接写运行时 `~\.trae-cn\user_rules\`。**

- **改已有规则的内容**：改源即生效，链接那头立刻就是新的，**不用跑同步**。
- **新增 / 删除规则**：必须跑 `aas sync`，否则源里有、运行时没有 = 规则从未生效。
- **为什么不能直接改运行时**：那里的文件不在任何 git 里（丢了退不回去），且同步一到就被冲掉 = 白改。
- **收尾自查**：加过规则后跑一次 `aas` 体检，「需建链接」应为 0。
