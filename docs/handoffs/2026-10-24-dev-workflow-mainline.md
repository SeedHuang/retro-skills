## 3 下个 session 第一件事（顺序不能颠倒）

**拿你当时的聊天记录，逐条核验 PRD 里的 `[已确认]` 标记。**

核验规则：

| 比对结果 | 处置 |
|---|---|
| 你说过「认 / 可以 / 就这么定」 | 保留 `[已确认]` |
| 只是我提议、你没表态 | **当场降级为 `[待确认]`**，并入 §11 |
| 你说过但意思被我写歪了 | 改正文，并在 §0.3 记一条 FZ |
| 记录里根本没有这条 | 标 `[FZ]`，不许当事实往下推 |

核验完成前**不写 S1**。
