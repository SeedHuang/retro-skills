## 3 内容分类与唯一源

| 类别 | 装什么 | 写在哪 | 谁改 |
|---|---|---|---|
| 逻辑组件 | 状态机、终态、守恒、可判定边界、失败面 | `tools/docgen/components/*.mjs`（spike 期：`tools/docgen-spike/**`） | 改代码 |
| 生成视图 | 组件渲染出的整份 markdown | `rules/*.md`、`skills/*/SKILL.md`、`agents/*.md` | 禁止手改 |
| 叙述正文 | 何时用、怎么做、为什么 | 组件的字面量格 / JSDoc | 改组件源 |
| 过程记录 | 交接词、复盘、报告、审查账、历史快照 | `docs/handoffs/`、`docs/superpowers/retro/`、`docs/reports/`、`docs/superpowers/reviews/` | 手写 |

**唯一源**：同一逻辑只存在于组件一处；视图是派生物；叙述只能引用 `comp:<Name>`，不能复述逻辑。PRD / plan 属上游叙述，手写。

## 4 评审规则

1. 名单按议会点将矩阵；本仓形态必选**读者 + 审计**，技术 PRD 按需加产品 / 后端 / 测试。
2. 一次只开卷「当前 PRD + 本索引」；不重审已通过且依赖未变的 PRD。
3. 通过 = 阻断项（P0）= 0 且必须修项 ≤ 5（每条有明确修法）；不通过 = 阻断项 > 0 或必须修项 > 5，列**最多 5 个必须修项**，不铺开。
4. 评审记录落 `.session/reviews/<那一次>/`；处置完整目录迁 `docs/superpowers/reviews/`。

## 5 全局不做（各 PRD 不再重复）

| # | 不做 | 何时重新考虑 |
|---|---|---|
| N1 | 全量迁移 | 单类文档连续两次因手写出错 |

| N8 | 改 aas 分发 | 分发成为瓶颈 |

## 6 变更规则

- 改共享决策：改本索引 + 记录日期 / 出处；受影响 PRD 标「需重审」。
- 改单个 PRD：只审该 PRD + 本索引。
- 已通过 PRD 冻结；被取代时原文保留（历史记录）。
