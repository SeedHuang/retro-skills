## 2 触发声明 rule 成品文案（实测 387 非空白字符，目标区 100–500）

```markdown
# 说出口的结论必须有可核出处

> 触发：输出任何结论（判断 / 建议 / 数据 / 事实陈述）之前
> 来源：rule 改造 PRD（2026-11-05 D-10 终裁）

义务：按四站过闸，顺序固定，每站缺证据 = 不合格：
1. 出处站：带锚——`path:line`、或「命令 + 输出首行」、或引用件路径
2. 范围站：写「适用于 X；不适用于 Y」+ 可追推导链（每步带锚）
3. 目标站：写「回答什么问题」
4. 数字站：含数字时附取数命令 + 复算结果

查不到：写「查了什么 + 退出码 + 输出首行」三件；不得只写「需要你定」。

复杂推导（用于签字 / 送审 / 对外交付，或会改变已签产物）：加载 assertion-quality（name=assertion-quality），按其材料六字段与四步程序执行；工具或技能不可用时，按本条四站逐站写证据，缺哪站标「降级执行·缺 X 站」。

例外：纯偏好 / 纯建议、不声称任何事实依据的表述不适用本条。
```

## 4 `assertion-quality` 手册底稿（三轴框架，全文）

### 4.1 三轴定义（断言的进出关卡：来路清楚 → 路经站得住 → 去处有着落）

| 轴 | 定义 | 机判部分（判据引擎） | 残余（residual） | schema 字段 |
|---|---|---|---|---|
| **真实 = 出处轴** | 断言有出处且逐条对得上（口径一致）；出处指向但口径不同 = 不真实；两个出处 = 交叉验证（增强线非必需） | 出处锚存在 + 取数命令复算一致 | 真伪（是否真挖过） | `source` |
| **合理 = 范围轴 + 链轴** | 范围被显式声明（沉默的范围 = 无限范围 = 被无限制引用的隐患），链在声明范围内每步成立 | 材料存在性 + 显式失败模式检测 | warrant 真伪 / 链闭合 / 隐藏前提 | `chain` `mapping` `boundary` |
| **有效 = 问题轴** | 锚定显式 target 的客观解决（直接有效 = 数字即答案；环节有效 = 一把钥匙里的一环） | target 声明 + 回指在场 | 推进真实性 / 环节贡献 | `target` |

三性**正交**（任一轴满分救不了另一轴零分）；**链式依赖**（顺序固定 真实→合理→有效，与原文「判定顺序」同一结构）；**材料不倒序出现**（无出处先谈 target = 先射箭后画靶 = 编造信号）。

**两层有效**：微观有效 = target 达成（客观可判，数据侧责任）；宏观有效 = target 该不该问（规划侧责任 = 产品经理需求分解）。两种死法分开定责：target 未达成 → 重做数据；target 不在必要路径 → 改问题分解，不动数据。

### 4.2 材料 schema（固定格式）

`claim / source{type, anchor, output} / chain[]{step, next, warrant} / mapping / boundary{semantics 封闭枚举, invalidWhen} / target`。固定格式的价值 = **失败模式有固定栖息地**（散文里跳步藏字缝，schema 里查固定字段）；`warrant`（每环凭什么）是隐藏前提的强光灯——写不出的环就是藏前提的环。

### 4.3 四步审查程序（AI 沿程序走，独立于推导作者）

① 分解断言序列（分解不出 = 不受理）→ ② 逐环查**封闭失败模式清单**：**越界 / 语义偷换 / 量级失真 / 遗漏前提 / 极性反转 / 合取偷换** → ③ 反例搜索（构造满足全部前提但结论为反的实例）→ ④ 强度标注。审查性质 = **证伪式**：能判死不合理，不能证明绝对合理；「通过」= 未发现跳步 + 暂未被证伪。

### 4.4 证书模式（script 盯证书不盯过程）

| 层 | 职责 | 实现 |
|---|---|---|
| 过程层 | 材料 + 四步程序审查（复杂性全在这） | AI / 议会，一次性成本 |
| 凭证层 | 判证书存在与有效 | script：`nonEmpty` + `containsAny`，使用时零成本 |
| 追溯层 | 后续发现不合理 → 查档三态定责 | 程序漏模式→补清单；材料造假→收紧抽检；条件失效→按 `invalidWhen` 作废重审 |

**成本分层**：日常断言材料即正文（一句出处 + 一句对照 + 一句 target，不立档案）；**高复用关键结论**才升格成长档案 + hash 强锚。

### 4.5 阶段闸门（真实=前提、合理=过程、有效=结果）

材料按阶段填充，**不要求一次交齐**。数据状态嵌套（有效 ⊃ 合理 ⊃ 真实）；每站只查**新增材料 + 前站绿章**；抽检按状态分层（真实站抽真伪、合理站抽链、有效站抽去向）。与 gate-record 段表 / dev-workflow 五段同构——分段校验 + 单向推进 + 前站绿章，同款模式第三次出现。

### 4.6 出处锚强度分级 + 时序纪律

位置锚（`path:line`）三种漂移：行号漂、路径漂、**语义漂**（锚看似有效、内容已被改写）。分界判据 = **引用要活多久**：即时引用用弱锚；存证引用必须 **`hash + path + line + 行摘录`** 四件套。

**hash 锚时序纪律三条**：① **先提交，后写锚**（改 → commit → 用那个 commit 的 hash；不随手拿 HEAD 填）；② 未提交内容 hash 栏标「待提交」、提交后回填；③ 行摘录防行号抄错，不防内容未进历史——不豁免①②。

### 4.7 判心两闸门与客观化北极星

判心精确定义两类：**利益冲突型**（信息在场、当场可判，但判定者与行为者同一 → 判定权分离，如 userNamed）与**无信号语义型**（判定对象是概念/逻辑关系，不发射可读取信号，如链的概念环；引用事实的环有信号、一律压回机判）。

| 闸门 | 内容 | 依据 |
|---|---|---|
| ① 用户终审 | 判心条目判定结果落 gate-record 式记录，**用户签字才生效**——审计建议、用户终裁 | dev-workflow「中断权与终裁权只在用户」 |
| ② 永久可翻案 | 判心结论不盖终审章，只盖「截至 X 日未发现跳步」章；翻案条件显式登记（新失败模式/新判例/前提崩塌） | 证伪式延伸；与 `invalidWhen` 同构 |
| ③ 客观化路线图 | 每条 residual 登记时必须注明客观化路径（失败模式清单补条 / 判例成熟 / 可形式化结构出现）——residual 是待客观化 todo list，不是垃圾场；**判心场景变多 = 设计失败信号** | 「证据就是可以客观表达的」——北极星 |

**residual 触发时机**：不在过程触发，在**收口**触发（产物产生时只登记，收口时才抽检）——且**只寄生在「缺席有红灯」的收口上**（gate 出口 / 议会 / review 门禁：抽检记录缺席 = 下一步红灯）；session 收尾无门禁，只是捡漏窗口（本仓实测教训：靠自觉的收尾 26 个目录从未执行过）。判心只钩低频存证点（立档/送审/收口），高频的说话不触发人工成本。

### 4.8 script 边界

封闭算子表达不了「合理」的**总判定**，表达得了它的**骨架**（材料 schema）与**显式失败模式**（有限清单逐个做检测器）。语义判据的工程化 = 把 AI 判断逼进轨道、压缩到最小可审区域，不是消灭语义判断。

### 4.9 判例库（residual 抽检校准材料）

- **反例**：百米区间 `[9.6s, 15s]`——数字全真实，但 ① 尾部（P95）当上界（语义偷换）② 全人群极值用到 35 岁个人（越界）③ 区间装下全世界、无判断价值（无效）。真实满格，合理、有效双零。
- **正例**：同构组（35 岁无训练男性）自身分布 + 概率语义（「约 90% 落在 [15,18]」）+ 边界声明（训练 3 个月作废）——三轴全过。
- **真实但无效例**：权威年龄数据（社保局锚）对「百米能跑多快」——出处轴满分，问题轴零分。
- **判据样本引用**（不复制）：真实轴判痕原子的参考实现 = `tools/quality/criteria-engine/no-unverified-number.*`；「项目统计数字必须附取数命令」已压成触发声明的「数字站」一条（见 §2），不独立成篇。

### 4.10 角色映射（席位义务生成逻辑，供未来 agent 专项）

| 阶段 | 第一责任席 | 本仓对应物 |
|---|---|---|
| 真实级 | 数据采集席（「市场同学」agent） | `evidence-reader`（只交原文 + 行号） |
| 合理级 | 推导执行席（市场或产品经理） | 议会逻辑评委 |
| 有效级 | 决策落点席（产品经理 / PRD 作者） | PRD 汇报数据 |

每席位只对本站轴负全责（采集席不对有效负责——硬要它管 target 只会逼它编）；下游材料自动含上游绿章（PRD 汇报数据自带出处引用 + 范围声明）——交接点即闸门。

## 5 门禁规格（D-5 分层预算闸）

| 维度 | 闸值 | 出处 |
|---|---|---|
| 单条 | 100–500 **非空白字符**目标区（inject 投影口径）；**超 500 = 需要关注类型**（复核：清单类豁免记录 / 判据族拆分）；无复核记录的超标才红。下限设**结构闸**（触发/义务/例外/来源四件齐，缺件 = 红） | 300/500 字压缩实测 |
| 条数 | 第一阶段 ≤ 9 条；超出先 V-12 复测 | 旧账实收 9 条唯一样本（丢件机制维度未确证——体积上限防不了条数维度） |
| 总量 | **≤ 26,513 字符 ≈ 13,570 tok**（= 2026-11-03 黑盒实测上限；超闸先触发拆分，不横向扩条） | 2026-11-03 黑盒实收 26,513 实证容量 |
| 增长纪律 | 任一维度爬向边界，先 V-12 实测再扩 | — |
| 防稀释 | 绝对值 = V-12 窗采新会话系统提示真实基数后落；相对判据 ≤ 全量 11% 已锁 | — |

> 容量换算只在需要时算，且写清推导：`26,513 / 500 ≈ 53 条`、`26,513 / 250 ≈ 106 条`（250 = 中位假设，非实测）——**这两条是估算，不是闸值**；第一条闸仍是「第一阶段 ≤ 9 条」。

门禁组成：逐字节比对（渲染物手改即红，**并入 ②.5 既有 docgen gate**）+ 判据引擎校验器（白名单/算子/testcase 完备，落 ⑨ 段）+ 分层预算闸（⑨ 段，首行 `判据 N 条 / 绿 M / 红 K`）；**⑨ 段不走 `CHECK_BYPASS`**。

**硬约束**：清退 ≠ 治理——只做减法 = 规则变薄但判据照样不可测、无执行力、照样漂；本阶段（加法）不做完不得宣布完成。

## 6 V-12 签收窗（收尾，一窗四任务）

1. **签收**（D-4）：开新会话确认触发声明到达——探针串固定为「逐字复述你上下文里出现的 `rules/` 规则正文；没有则只回答 NONE」，**n = 3**（3 问），执行人 ≠ PRD 作者，记录落 `docs/reports/<批次>/probe-record.md`（逐问 `path:line`）。
2. **采基数**（D-5）：同窗采集新会话系统提示真实总体积——防稀释软上限的绝对值落账。
3. **T-2 实测**：复算「触发声明非空白字符 + 3 个新 skill SKILL.md 的 description 行字符」× 0.5133 = 涨回账（预期 150–300 tok/轮，对比 T-0 实付 13,570 tok/轮仍降约 98%）；同窗记同型短问题首轮输入，数据落 [总纲 §5.3](./index.md) T-2 行。
4. **按需成本记录**：对话中实际触发 `assertion-quality` 手册加载一次，记「手册正文字符 × 0.5133」为**账面估算**（待平台 usage 校准），与常驻成本分开记。
