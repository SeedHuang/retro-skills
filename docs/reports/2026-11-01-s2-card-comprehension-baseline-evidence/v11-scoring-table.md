## 0 用法（三条）

1. **答题实例只给卡**：只给该席卡面全文，不给本文件、不给任何外部文件、不给任何门禁或检查提示（`V-11-b` 测量隔离）。
2. **判分实例只给「卡面 + 答卷 + 本节计分表」**：逐条 0/1，不做推理加权。
3. **判定面 = 卡面文本本身**：计数对象是该席卡面的**全文**（含前言、各段正文、表格），**不查任何外部文件**。判定串为逐字子串，区分大小写、逐字含其内部空格与全角标点。

## 3 §判分口径

1. **逐项 0/1**：每条按上表「判法」二值打分，不给部分分、不给区间分；命中判定串与否只看卡面全文（区分大小写、逐字匹配，含其内部空格与全角符号）。
2. **两个判分实例逐项取交集**：同一答卷由两名判分实例独立打分，**两人都判 1 才记为 1**，任一人判 0 则该项不记。
3. **分歧项不进交集、另记**：两人对该项判定不一致的，该项不计入交集得分，单独登记为「分歧项」并写明双方判定；分歧项不计入漏项数。
4. **分歧 > 3 项须启第三实例裁定**：同一席同一答卷的分歧项超过 3 项时，启动第三个独立实例对分歧项逐条裁定，裁定结果即为该项最终判定；裁定记录与本表同目录留档。
5. **只给卡面，不给任何外部文件或门禁提示**：答题与判分都不得引入卡面之外的任何文件、台账或校验提示；本表与答卷之外的输入一律不作为判定依据。
