## 3 读法（比分数更重要）

1. **增益来自一处可见差异**：Q5 从 2/7 → 4/7，因为新卡把类型列**画成「人工判定」**，旧卡画的是 `manual`；读者不必再猜「manual 是不是被禁的枚举」。其余 4 题里，Q1/Q2/Q3 **两版并列**。
2. **核心行为本来就已被读懂**：Q1–Q3 全卷 19 项里旧卡拿到 19/20，说明「该做什么 / 怎么判 / 别越界」这些信息旧卡**有**（在「职责 / 约束 / 边界 / 输出格式」的散文里），只是以 `id + 7 列表格` 呈现，读者照样能读懂——**所以 S2 的主要收益不是「读得懂」，而是「不必查 predicates 表」「可逐行对账」**。
3. **Q4 揭示的是「信息缺失」而非「呈现差」**：两版都答不出「真实路径 / 可跑命令 / 产物字段名 属于允许项」，因为**这张卡里根本没有这条**（它在 PRD §3.4 `:176`）。这条对 S2 是一个具体落点：**「许的三类」必须写进卡面**（建议进「边界」段或「禁止」段末），否则 F-06 的守卫上线后，读者不知道哪些英文是被允许的。
4. **Q2 必③ 两版同失**：答的都只写「要求补 path:line」，没有给本席自己的 `文件:行号`——这属模型行为问题，不属卡面问题，不计入卡面收益。

**结论（写给 S2）**：
1. 目标形态**稳定为正**（三席全正，+2 ~ +8），但不是「大幅提升」；收益集中在**类型列中文化**与**清单/结构可判**两处。

## 7 改后复测（V-11 验收结论，2026-11-02）

> 口径：与 §1 / §6 同一题面、同一**冻结**计分表（`.session/reviews/2026-11-01-2200-s2-d17-increment/v11-scoring-table.md` §2，34 项）。每席 **2 个独立判分实例**逐项 0/1，两人都判 1 才记 1；分歧项另记、不计入漏项（计分表 §3.2–§3.3）；同席分歧 > 3 项启第三实例逐条裁定（§3.4）。
> 被测答卷 = 同一目录的 `v11-answers-<席>.md`（答题实例只给该席卡面、不给外部文件，`V-11-b` 测量隔离）。
> 时序说明：答卷写作与判分时，「产物字段名只许…」一句位于「边界」段末；同批把它移入「输出格式」段末（**逐字未改**，只为让「边界」段与 S6 的 `renderBoundary` 逐字相等）。计分表按判定串判 0/1、不看段位，故分数不受该移动影响。

**读法（写给 S2 收尾）**：
1. 三席全部过线，`L_after` 合计由 43 降到 9（−34 项，约 −79%）；基线报告 §6 指出的两个内容缺口（Q4「许的三类」、Q2「缺字段 = 废卡」）在改后答卷里已可答出。
2. **剩余未达成项集中在两处**：① `Q3-必⑤`（「不得代他人填写其本人应填的表」在卡上有，但答卷未答出该行为）三席皆失，属答题侧问题，不是卡面缺句；② `Q5-必③`（「类别行 ↔ 类型列一一对应」的读法）与 `Q5-必⑤`（「人工判定要做的事 = 写原文引句」）在 audit / detective 两席失，属卡面只给值、没给读法说明——记入缺口，不在本块改判据。
